# BatchFox Releases

Official release channel for **BatchFox** — signed installer distribution and the auto-update manifest.

- **Installers** are published as **GitHub Releases**, Authenticode-signed by *BatchFox Studio LLC* (Azure Artifact Signing).
- **The update manifest** is served at **https://updates.batchfox.app/manifest.json** — GitHub Pages, from the `/docs` folder of this repo. The BatchFox desktop app checks that URL for updates.

## Layout
- `docs/manifest.json` — the current update manifest (regenerated by the release build pipeline on each release).
- `docs/CNAME` — binds GitHub Pages to `updates.batchfox.app`.
- Release binaries live under **Releases**, not in the repo tree.
